# 報告問答用 LangGraph，不受 ADR-0001 的輸出檢查約束

報告問答（Report Q&A）讓使用者針對單一評估個案追問。實作上用 LangGraph 的 ReAct agent，透過 `langchain-openai` 的 `ChatOpenAI` 指向 OpenRouter，模型沿用 `anthropic/claude-haiku-5.5`（ADR-0004）。工具有兩個：一個讀這份個案的判定，一個包裝現有的 `retrieve_evidence` 來檢索語料。現有的模型閘道、檢索與報告解釋都不改寫成 LangChain。這個專案是開發者個人使用、不對外上架，引入 LangChain 主要是為了學習；把它限制在新的問答模組裡，正式報告的流程就不會受影響。

問答只有一條約束：判定以報告為準，不能推翻。這條只寫在 system prompt 裡，不用程式驗證。ADR-0001 對報告解釋的其他限制在問答中都不適用：
- 每句都要附引用（問答只在用到檢索結果時附來源）
- 解釋文字不得含數字（問答可以直接引用判定裡的數值）
- 禁用詞檢查與不合格重試
- 封閉的三種建議行動

另外，問答可以用模型本身的一般知識回答，但要跟語料來源分開標示。之所以這樣取捨，是因為評估個案和報告才是正式紀錄，問答的對話不保存，也不屬於評估個案。

## Consequences

- 問答的回答可能和報告用詞不一致，甚至超出語料範圍；正式紀錄仍以報告為準。
- `tests/` 用假模型測 graph 的工具呼叫與權限；真模型只在 `evals/report_chat/` 跑，結果由人工判讀，不打分數。
